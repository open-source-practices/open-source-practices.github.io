Anything in this folder is copied to the root of the built site untouched.

- `image.png` here is served at `/image.png` and referenced in Markdown as `![](/image.png)`
- `.nojekyll` stops GitHub Pages running Jekyll over the output. Leave it in place.
- Add a `CNAME` file containing just your domain (e.g. `example.org`) if you use a custom domain.
